# Estructura de Views

Esta carpeta concentra el frontend del proyecto.

- `Home/`: vistas Razor generales del proyecto ASP.NET Core MVC.
- `Reportes/`: vistas Razor relacionadas con reporteria.
- `Shared/`: layouts y parciales compartidos por las vistas Razor.
- `WebForms/`: frontend Web Forms modular.
- `packages/`: dependencias NuGet usadas por el proyecto Web Forms.

Dentro de `WebForms/`:

- `Auth/`: login y pantallas de autenticacion.
- `Cliente/`: pantallas para usuarios cliente.
- `Admin/`: pantallas para administradores.
- `Modules/`: pantallas operativas del aeropuerto.
- `Info/`: pantallas informativas como servicios y soporte.
- `Shared/`: master pages y elementos comunes de Web Forms.
- `Content/` y `Scripts/`: estilos y scripts locales del Web Forms.
